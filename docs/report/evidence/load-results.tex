Dari 88.338 request yang dikirim, 88.308 mendapat respons sukses. Throughput-nya mencapai 980,26 respons sukses per detik, sedangkan 30 request lainnya menghasilkan HTTP 503, sebagaimana dicatat dalam \path{evidence/load-statuses.json}. Dengan demikian, error selain 429 sebesar 0,034\%, masih di bawah batas 1\%.

API tidak menghasilkan 429 pada pengujian ini. Auth menghasilkan 18 respons 429 selama login dan refresh, tetapi retry berhasil sehingga tidak ada sesi worker yang gagal. Angka Auth tersebut dilaporkan terpisah agar pembatasan request terkendali tidak tercampur dengan error pada pembacaan hazard.

Delay langsung dari sumber PVMBG terukur 3.004,46 ms, sementara p95 respons sukses BMKG sebesar 124,52 ms. Hasil ini memenuhi batas 300 ms ketika kedua sumber dibaca bersamaan. Sampel TCP juga menunjukkan sedikitnya 50 koneksi pada interval 89,00 detik, melebihi syarat 60 detik. Karena collector mengambil sampel sekitar sekali per detik, kesimpulan mengenai koneksi mengikuti resolusi pengukuran tersebut.
