\chapter{Deskripsi Umum Sistem}
Platform ini mengumpulkan data kebencanaan dari simulasi BMKG dan PVMBG agar client dapat membacanya melalui satu API. Kedua sumber memiliki format dan cara autentikasi yang berbeda. Aggregator menyamakan data tersebut menjadi \texttt{HazardEvent}, kemudian menyimpannya di Canonical Store, yaitu penyimpanan utama untuk data yang sudah mengikuti format bersama. Dengan demikian, client tidak perlu melakukan pemetaan ulang untuk setiap sumber.

Data yang diterima client disesuaikan dengan identitasnya. Media memperoleh ringkasan, sedangkan Tim Lapangan dan BNPB internal dapat membaca data lengkap. Selain tersedia melalui API, setiap event baru atau revisi event diteruskan ke NATS JetStream. Dashboard Consumer dan Notifier Consumer kemudian mengolahnya secara terpisah, sehingga gangguan pada salah satu consumer tidak menghentikan consumer lainnya.

Milestone 1 berfokus pada alur pengambilan, pembacaan, dan distribusi data tersebut. Implementasinya mencakup autentikasi sumber, polling, pemetaan, penyimpanan, pembatasan akses client, serta distribusi event ke beberapa consumer. Sesuai spesifikasi M1 dan dokumen terpusat, seluruh data pada tahap ini bersifat sintetis \cite{m1,central}. Sistem baru menangani \texttt{SEISMIC} dan \texttt{VOLCANIC}; penerimaan laporan lapangan dan pengiriman SMS sungguhan belum termasuk dalam implementasi.
